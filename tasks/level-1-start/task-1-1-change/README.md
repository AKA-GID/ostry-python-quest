# 🌶️ Задача 1.1 · Сдача

> **Уровень 1 «Первый укус»** · острота: 🌶️ · тема: ввод, вывод, арифметика

## 📖 Легенда

Маша зашла в магазин за булочкой. Булочка стоит P рублей, а Маша протянула продавцу M рублей. Сколько рублей сдачи вернёт продавец?

## 📥 Формат ввода

Два целых числа, каждое на своей строке: цена P и сумма M, которую дала Маша.

1 ≤ P ≤ M ≤ 10000.

## 📤 Формат вывода

Одно число — сдача в рублях.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
45
100
```

Вывод:

```text
55
```

**Пример 2**

Ввод:

```text
130
200
```

Вывод:

```text
70
```

**Пример 3**

Ввод:

```text
50
50
```

Вывод:

```text
0
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

`int(input())` читает целое число. Сдача — это то, что дали, минус то, что стоит.

</details>
