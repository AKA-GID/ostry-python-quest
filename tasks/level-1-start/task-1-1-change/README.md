# 1.1 · Сдача

В кассе нужно посчитать сдачу. Вычти сумму покупки из суммы, которой заплатили.

Сумма сдачи равна `paid - price`.

## Получить входные данные

Запросите `GET /api/tasks/1.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "1.1",
  "input": {
  "price": 45,
  "paid": 100
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "1.1",
  "answer": {
  "change": 55
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
