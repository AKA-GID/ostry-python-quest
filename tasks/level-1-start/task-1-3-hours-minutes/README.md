# 🌶️ Задача 1.3 · Часы и минуты

> **Уровень 1 «Первый укус»** · острота: 🌶️ · тема: ввод, вывод, арифметика

## 📖 Легенда

Фильм идёт M минут. Сколько это полных часов и сколько минут остаётся сверху?

## 📥 Формат ввода

Одно целое число M.

1 ≤ M ≤ 10000.

## 📤 Формат вывода

Два числа через пробел: часы и минуты.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
135
```

Вывод:

```text
2 15
```

**Пример 2**

Ввод:

```text
60
```

Вывод:

```text
1 0
```

**Пример 3**

Ввод:

```text
45
```

Вывод:

```text
0 45
```
