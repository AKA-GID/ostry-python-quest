# 1.3 · Часы и минуты

Переведи общее количество минут в полные часы и оставшиеся минуты.

В ответе укажи целое число часов и остаток минут.

## Получить входные данные

Запросите `GET /api/tasks/1.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "1.3",
  "completed": false,
  "input": {
  "minutes": 135
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "1.3",
  "answer": {
  "hours": 2,
  "minutes": 15
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
