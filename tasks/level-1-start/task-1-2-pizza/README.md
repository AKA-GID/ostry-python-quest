# 1.2 · Пицца на компанию

Узнай, сколько целых пицц нужно заказать, чтобы каждому человеку досталось заданное количество кусочков. В одной пицце 8 кусочков.

Раздели нужное количество кусочков на 8 и округли число пицц вверх.

## Получить входные данные

Запросите `GET /api/tasks/1.2/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "1.2",
  "input": {
  "people": 3,
  "pieces_per_person": 2
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "1.2",
  "answer": {
  "pizzas": 1
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
