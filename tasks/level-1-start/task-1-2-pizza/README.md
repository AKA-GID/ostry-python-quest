# 🌶️ Задача 1.2 · Пицца на компанию

> **Уровень 1 «Первый укус»** · острота: 🌶️ · тема: ввод, вывод, арифметика

## 📖 Легенда

У тебя дома собрались n человек (вместе с тобой). Каждый хочет съесть по k кусков пиццы. В пиццерии одна пицца — это 8 кусков, и заказывать можно только целые пиццы. Сколько пицц нужно заказать, чтобы всем хватило?

## 📥 Формат ввода

Два целых числа, каждое на своей строке: n и k.

1 ≤ n ≤ 100, 1 ≤ k ≤ 10.

## 📤 Формат вывода

Одно число — количество пицц.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
3
2
```

Вывод:

```text
1
```

**Пример 2**

Ввод:

```text
4
3
```

Вывод:

```text
2
```

**Пример 3**

Ввод:

```text
4
2
```

Вывод:

```text
1
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Нужно n·k кусков. Обычное деление `//` отбрасывает остаток, а нам нужно округлить вверх. Подумай: что даст `(x + 7) // 8`?

</details>
