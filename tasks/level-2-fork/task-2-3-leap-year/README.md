# 2.3 · Високосный год

Определи, является ли год високосным по григорианскому календарю.

Високосный год делится на 4, кроме годов, кратных 100; годы, кратные 400, всё же високосные.

## Получить входные данные

Запросите `GET /api/tasks/2.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "2.3",
  "input": {
  "year": 2024
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "2.3",
  "answer": {
  "is_leap": true
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
