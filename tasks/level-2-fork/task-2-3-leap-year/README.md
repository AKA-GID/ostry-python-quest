# 🌶️ Задача 2.3 · Високосный год

> **Уровень 2 «Развилка»** · острота: 🌶️ · тема: условия if / elif / else

## 📖 Легенда

Год високосный, если он делится на 4, но не делится на 100. Исключение: если год делится на 400, он тоже високосный. Определи, високосный ли год.

## 📥 Формат ввода

Одно целое число — год.

1 ≤ год ≤ 9999.

## 📤 Формат вывода

Слово `YES`, если год високосный, и `NO`, если нет.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
2024
```

Вывод:

```text
YES
```

**Пример 2**

Ввод:

```text
2023
```

Вывод:

```text
NO
```

**Пример 3**

Ввод:

```text
1900
```

Вывод:

```text
NO
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Остаток от деления: `year % 4 == 0`. Свяжи условия через `and` и `or` и не забудь про скобки.

</details>
