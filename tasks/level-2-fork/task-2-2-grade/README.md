# 🌶️ Задача 2.2 · Какая оценка

> **Уровень 2 «Развилка»** · острота: 🌶️ · тема: условия if / elif / else

## 📖 Легенда

Учитель ставит оценку за контрольную по баллам: 90 и больше — «5», от 75 до 89 — «4», от 50 до 74 — «3», меньше 50 — «2». Какую оценку получит ученик?

## 📥 Формат ввода

Одно целое число — набранные баллы.

0 ≤ баллы ≤ 100.

## 📤 Формат вывода

Одна цифра — оценка.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
95
```

Вывод:

```text
5
```

**Пример 2**

Ввод:

```text
75
```

Вывод:

```text
4
```

**Пример 3**

Ввод:

```text
49
```

Вывод:

```text
2
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Начни проверку с самой высокой оценки и иди вниз. Тогда в каждом `elif` не придётся писать два условия.

</details>
