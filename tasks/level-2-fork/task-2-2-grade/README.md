# 2.2 · Какая оценка

Переведи результат в баллах в школьную оценку: 0–49 — оценка 2, 50–69 — 3, 70–89 — 4, 90–100 — 5.

Верни одну целую оценку по указанному диапазону.

## Получить входные данные

Запросите `GET /api/tasks/2.2/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "2.2",
  "input": {
  "points": 75
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "2.2",
  "answer": {
  "grade": 4
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
