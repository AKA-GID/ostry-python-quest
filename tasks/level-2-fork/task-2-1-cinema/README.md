# 🌶️ Задача 2.1 · Билет в кино

> **Уровень 2 «Развилка»** · острота: 🌶️ · тема: условия if / elif / else

## 📖 Легенда

В кинотеатре цена билета зависит от возраста. Детям младше 7 лет вход бесплатный. От 7 до 17 лет включительно билет стоит 150 рублей, а с 18 лет — 300 рублей. Сколько заплатит зритель?

## 📥 Формат ввода

Одно целое число — возраст зрителя.

0 ≤ возраст ≤ 120.

## 📤 Формат вывода

Одно число — стоимость билета в рублях.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
5
```

Вывод:

```text
0
```

**Пример 2**

Ввод:

```text
12
```

Вывод:

```text
150
```

**Пример 3**

Ввод:

```text
30
```

Вывод:

```text
300
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Проверяй условия по порядку: `if` / `elif` / `else`. Особенно проверь возраста 6, 7, 17 и 18.

</details>
