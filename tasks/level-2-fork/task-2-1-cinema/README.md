# 2.1 · Билет в кино

Цена билета зависит от возраста: до 14 лет включительно билет стоит 150 рублей, старше 14 лет — 300 рублей.

Определи стоимость по возрасту.

## Получить входные данные

Запросите `GET /api/tasks/2.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "2.1",
  "completed": false,
  "input": {
  "age": 12
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "2.1",
  "answer": {
  "price": 150
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
