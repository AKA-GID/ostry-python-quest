# 🌶️🌶️ Задача 4.1 · Копилка

> **Уровень 4 «Пока не закипит»** · острота: 🌶️🌶️ · тема: цикл while

## 📖 Легенда

Миша мечтает о новой компьютерной игре за N рублей. Он решил копить: в первый день откладывает A рублей, а каждый следующий день — на D рублей больше, чем в предыдущий. Через сколько дней Миша сможет купить игру и сколько рублей будет в копилке в этот момент?

## 📥 Формат ввода

Три целых числа N, A и D через пробел.

1 ≤ N ≤ 10⁶, 1 ≤ A ≤ 1000, 0 ≤ D ≤ 1000.

## 📤 Формат вывода

Два числа через пробел: количество дней и сумма в копилке на конец этого дня.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
100 10 5
```

Вывод:

```text
5 100
```

**Пример 2**

Ввод:

```text
50 20 0
```

Вывод:

```text
3 60
```

**Пример 3**

Ввод:

```text
1 5 3
```

Вывод:

```text
1 5
```

## 📝 Примечание

В первом примере: 10 + 15 + 20 + 25 + 30 = 100, то есть ровно за 5 дней.

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Нужны три переменные: сколько дней прошло, сколько накоплено и сколько откладывать сегодня. Пока накоплено меньше N — повторяй.

</details>
