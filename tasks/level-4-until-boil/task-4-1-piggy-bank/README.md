# 4.1 · Копилка

В первый день положили `first_deposit` рублей. Каждый следующий день кладут на `daily_increase` рублей больше, чем в предыдущий. Найди первый день, когда накопится не меньше цели.

Верни номер этого дня и сумму в копилке после пополнения в этот день.

## Получить входные данные

Запросите `GET /api/tasks/4.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "4.1",
  "completed": false,
  "input": {
  "target": 100,
  "first_deposit": 10,
  "daily_increase": 5
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "4.1",
  "answer": {
  "days": 5,
  "saved": 100
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
