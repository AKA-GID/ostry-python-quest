# 4.3 · Бактерии в чашке

В чашке сначала несколько бактерий. Каждый час их количество удваивается. Узнай, через сколько полных часов их станет не меньше цели.

Верни минимальное число часов.

## Получить входные данные

Запросите `GET /api/tasks/4.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "4.3",
  "completed": false,
  "input": {
  "initial": 3,
  "target": 100
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "4.3",
  "answer": {
  "hours": 6
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
