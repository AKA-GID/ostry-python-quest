# 🌶️🌶️ Задача 4.3 · Бактерии в чашке

> **Уровень 4 «Пока не закипит»** · острота: 🌶️🌶️ · тема: цикл while

## 📖 Легенда

В чашке Петри живут a бактерий. Каждый час их число удваивается. Через сколько часов бактерий станет не меньше n?

## 📥 Формат ввода

Два целых числа a и n через пробел.

1 ≤ a ≤ n ≤ 10¹⁸.

## 📤 Формат вывода

Одно число — количество часов (если бактерий уже достаточно, ответ 0).

## 🧪 Примеры

**Пример 1**

Ввод:

```text
1 10
```

Вывод:

```text
4
```

**Пример 2**

Ввод:

```text
5 5
```

Вывод:

```text
0
```

**Пример 3**

Ввод:

```text
3 100
```

Вывод:

```text
6
```

## 📝 Примечание

В первом примере: 1 → 2 → 4 → 8 → 16. Через 4 часа бактерий 16, это не меньше 10.

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Пока бактерий меньше n — умножай их на 2 и считай часы.

</details>
