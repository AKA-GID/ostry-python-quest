# 3.2 · Шагомер

Даны шаги, пройденные за несколько дней. Найди их общее количество.

Сложи все числа в списке.

## Получить входные данные

Запросите `GET /api/tasks/3.2/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "3.2",
  "input": {
  "daily_steps": [
    4000,
    6500,
    5500
  ]
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "3.2",
  "answer": {
  "total_steps": 16000
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
