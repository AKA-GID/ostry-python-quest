# 🌶️🌶️ Задача 3.2 · Шагомер

> **Уровень 3 «Разгон»** · острота: 🌶️🌶️ · тема: цикл for и range

## 📖 Легенда

Ты носишь шагомер n дней подряд. Каждый вечер он показывает, сколько шагов ты прошёл за день. Сколько всего шагов за n дней?

## 📥 Формат ввода

В первой строке число n. Далее n строк, в каждой — число шагов за очередной день.

1 ≤ n ≤ 100, шагов за день от 0 до 50000.

## 📤 Формат вывода

Одно число — общее количество шагов.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
3
4000
6500
5500
```

Вывод:

```text
16000
```

**Пример 2**

Ввод:

```text
1
100
```

Вывод:

```text
100
```

**Пример 3**

Ввод:

```text
2
0
0
```

Вывод:

```text
0
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Заведи переменную-сумму, поставь её в 0 и в цикле читай по числу, прибавляя к сумме.

</details>
