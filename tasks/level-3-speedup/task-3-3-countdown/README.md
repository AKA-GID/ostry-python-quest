# 3.3 · Обратный отсчёт

Выведи числа обратного отсчёта, начиная с заданного числа и заканчивая 1, а затем слово «Пуск!».

Список чисел должен идти по убыванию; слово передай отдельной строкой JSON.

## Получить входные данные

Запросите `GET /api/tasks/3.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "3.3",
  "completed": false,
  "input": {
  "start": 3
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "3.3",
  "answer": {
  "numbers": [
    3,
    2,
    1
  ],
  "launch": "Пуск!"
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
