# 🌶️🌶️ Задача 3.3 · Обратный отсчёт

> **Уровень 3 «Разгон»** · острота: 🌶️🌶️ · тема: цикл for и range

## 📖 Легенда

Перед стартом ракеты нужен отсчёт. Выведи числа от n до 1 — каждое на новой строке, а в самом конце слово `Пуск!`.

## 📥 Формат ввода

Одно целое число n.

1 ≤ n ≤ 100.

## 📤 Формат вывода

Числа от n до 1 по одному в строке, затем строка `Пуск!`.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
3
```

Вывод:

```text
3
2
1
Пуск!
```

**Пример 2**

Ввод:

```text
1
```

Вывод:

```text
1
Пуск!
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

`range(n, 0, -1)` идёт от n вниз до 1. Третий параметр — шаг.

</details>
