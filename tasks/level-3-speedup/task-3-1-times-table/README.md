# 3.1 · Таблица умножения

Составь первые десять результатов умножения заданного числа на 1, 2, …, 10.

Положи десять результатов в список по порядку.

## Получить входные данные

Запросите `GET /api/tasks/3.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "3.1",
  "input": {
  "number": 3
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "3.1",
  "answer": {
  "table": [
    3,
    6,
    9,
    12,
    15,
    18,
    21,
    24,
    27,
    30
  ]
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
