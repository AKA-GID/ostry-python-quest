# 🌶️🌶️🌶️🌶️ Задача 6.2 · Самый высокий и самый низкий

> **Уровень 6 «Список острых»** · острота: 🌶️🌶️🌶️🌶️ · тема: списки

## 📖 Легенда

В классе n учеников, известен рост каждого. Найди рост самого высокого и самого низкого.

## 📥 Формат ввода

В первой строке число n. Во второй строке n значений роста через пробел.

1 ≤ n ≤ 100, рост от 100 до 220.

## 📤 Формат вывода

Два числа через пробел: максимальный и минимальный рост.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
4
150 162 148 170
```

Вывод:

```text
170 148
```

**Пример 2**

Ввод:

```text
1
155
```

Вывод:

```text
155 155
```

**Пример 3**

Ввод:

```text
3
160 160 160
```

Вывод:

```text
160 160
```
