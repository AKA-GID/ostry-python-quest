# 6.2 · Самый высокий и самый низкий

Найди наибольший и наименьший рост в списке.

Верни оба значения в одном JSON-объекте.

## Получить входные данные

Запросите `GET /api/tasks/6.2/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "6.2",
  "completed": false,
  "input": {
  "heights": [
    150,
    162,
    148,
    170
  ]
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "6.2",
  "answer": {
  "tallest": 170,
  "shortest": 148
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
