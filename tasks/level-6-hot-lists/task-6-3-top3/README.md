# 6.3 · Топ-3 игроков

Из списка результатов выбери три наибольших значения и расположи их от большего к меньшему.

Если одинаковые значения встречаются несколько раз, каждое учитывается.

## Получить входные данные

Запросите `GET /api/tasks/6.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "6.3",
  "completed": false,
  "input": {
  "scores": [
    10,
    50,
    30,
    20,
    40
  ]
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "6.3",
  "answer": {
  "top_three": [
    50,
    40,
    30
  ]
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
