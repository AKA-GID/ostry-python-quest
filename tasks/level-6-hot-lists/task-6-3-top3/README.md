# 🌶️🌶️🌶️🌶️ Задача 6.3 · Топ-3 игроков

> **Уровень 6 «Список острых»** · острота: 🌶️🌶️🌶️🌶️ · тема: списки

## 📖 Легенда

В игре n игроков, у каждого свои очки. Выведи очки трёх лучших игроков по убыванию. Если у нескольких игроков одинаковые очки, каждое значение считается отдельно.

## 📥 Формат ввода

В первой строке число n. Во второй строке n значений очков через пробел.

3 ≤ n ≤ 100, очки от 0 до 10⁶.

## 📤 Формат вывода

Три числа через пробел — три наибольших значения по убыванию.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
5
10 50 30 20 40
```

Вывод:

```text
50 40 30
```

**Пример 2**

Ввод:

```text
3
1 2 3
```

Вывод:

```text
3 2 1
```

**Пример 3**

Ввод:

```text
4
7 7 5 7
```

Вывод:

```text
7 7 7
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

`sorted(a, reverse=True)` сортирует по убыванию, срез `[:3]` берёт три первых. `print(*lst)` печатает элементы списка через пробел.

</details>
