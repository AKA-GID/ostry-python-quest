# 🌶️🌶️🌶️🌶️ Задача 6.1 · Средний балл

> **Уровень 6 «Список острых»** · острота: 🌶️🌶️🌶️🌶️ · тема: списки

## 📖 Легенда

В дневнике n оценок. Найди средний балл.

## 📥 Формат ввода

В первой строке число n. Во второй строке n оценок через пробел.

1 ≤ n ≤ 100, оценки от 2 до 5.

## 📤 Формат вывода

Одно число — средний балл с двумя знаками после запятой.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
5
5 4 5 3 5
```

Вывод:

```text
4.40
```

**Пример 2**

Ввод:

```text
2
3 4
```

Вывод:

```text
3.50
```

**Пример 3**

Ввод:

```text
1
5
```

Вывод:

```text
5.00
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

`list(map(int, input().split()))` превращает строку с числами в список. `sum(a)` — сумма. Для двух знаков: `print(f"{x:.2f}")`.

</details>
