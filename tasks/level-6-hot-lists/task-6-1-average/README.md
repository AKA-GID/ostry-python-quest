# 6.1 · Средний балл

Найди среднее арифметическое всех чисел в списке.

Верни число; в JSON дробная часть записывается через точку.

## Получить входные данные

Запросите `GET /api/tasks/6.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`. В поле `completed` будет `true`, если задачу уже решил кто-то из команды, иначе `false`.

Пример ответа сервера:

```json
{
  "task_id": "6.1",
  "completed": false,
  "input": {
  "scores": [
    5,
    4,
    5,
    3,
    5
  ]
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "6.1",
  "answer": {
  "average": 4.4
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
