# 5.2 · Шахматная доска

Составь прямоугольную доску из `#` и `.`. В левом верхнем углу должен быть `#`; соседние по горизонтали и вертикали клетки чередуются.

Верни каждую строку доски отдельной строкой списка.

## Получить входные данные

Запросите `GET /api/tasks/5.2/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "5.2",
  "input": {
  "rows": 3,
  "columns": 4
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "5.2",
  "answer": {
  "board": [
    "#.#.",
    ".#.#",
    "#.#."
  ]
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
