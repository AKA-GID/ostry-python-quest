# 🌶️🌶️🌶️ Задача 5.2 · Шахматная доска

> **Уровень 5 «Двойной удар»** · острота: 🌶️🌶️🌶️ · тема: вложенные циклы и строки

## 📖 Легенда

Нарисуй шахматную доску из символов: чёрная клетка — `#`, белая — `.`. Левая верхняя клетка всегда чёрная, дальше клетки чередуются по строке и по столбцу.

## 📥 Формат ввода

Два целых числа n и m через пробел: число строк и столбцов.

1 ≤ n, m ≤ 30.

## 📤 Формат вывода

n строк по m символов каждая.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
3 4
```

Вывод:

```text
#.#.
.#.#
#.#.
```

**Пример 2**

Ввод:

```text
2 2
```

Вывод:

```text
#.
.#
```

**Пример 3**

Ввод:

```text
1 5
```

Вывод:

```text
#.#.#
```

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Клетка с номером строки i и столбца j чёрная, когда `(i + j)` чётное. Собирай каждую строку в переменную внутренним циклом и печатай её после.

</details>
