# 5.1 · Лесенка

Построй лесенку из заданного количества строк. В первой строке одна звёздочка, в каждой следующей на одну больше.

Верни строки лесенки списком.

## Получить входные данные

Запросите `GET /api/tasks/5.1/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "5.1",
  "input": {
  "height": 3
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "5.1",
  "answer": {
  "rows": [
    "*",
    "**",
    "***"
  ]
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
