# 🌶️🌶️🌶️ Задача 5.1 · Лесенка

> **Уровень 5 «Двойной удар»** · острота: 🌶️🌶️🌶️ · тема: вложенные циклы и строки

## 📖 Легенда

Нарисуй лесенку из звёздочек: в первой строке одна звёздочка, во второй две, и так далее до n строк.

## 📥 Формат ввода

Одно целое число n.

1 ≤ n ≤ 50.

## 📤 Формат вывода

n строк: в i-й строке ровно i символов `*`.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
3
```

Вывод:

```text
*
**
***
```

**Пример 2**

Ввод:

```text
1
```

Вывод:

```text
*
```

**Пример 3**

Ввод:

```text
5
```

Вывод:

```text
*
**
***
****
*****
```

## 📝 Примечание

Попробуй решить двумя способами: с вложенным циклом и с умножением строки (`"*" * 3`).

<details>
<summary>💡 Подсказка (открой, если застрял)</summary>

Внешний цикл — по строкам, внутренний — по звёздочкам в строке. Чтобы печатать без перехода на новую строку: `print("*", end="")`.

</details>
