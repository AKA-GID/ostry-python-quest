# 5.3 · Гласные

Посчитай русские гласные буквы в тексте. Учитывай и заглавные, и строчные буквы.

Используй набор гласных `а, е, ё, и, о, у, ы, э, ю, я`.

## Получить входные данные

Запросите `GET /api/tasks/5.3/input`. Сервер вернёт объект задачи; входные значения находятся в поле `input`.

Пример ответа сервера:

```json
{
  "task_id": "5.3",
  "input": {
  "text": "Привет мир"
}
}
```

## Отправить ответ

Вычислите результат по фактическим значениям от сервера и отправьте `POST /api/submit`:

```json
{
  "task_id": "5.3",
  "answer": {
  "count": 3
}
}
```

Числа выше показывают только формат данных. Сервер может выдать другие входные значения. В `answer` оставьте указанные поля и передайте значения нужных типов.
