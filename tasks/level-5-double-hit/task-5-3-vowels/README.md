# 🌶️🌶️🌶️ Задача 5.3 · Гласные

> **Уровень 5 «Двойной удар»** · острота: 🌶️🌶️🌶️ · тема: вложенные циклы и строки

## 📖 Легенда

Ты проверяешь, сколько гласных в слове или фразе. Гласные русские буквы: а, е, ё, и, о, у, ы, э, ю, я. Заглавные буквы тоже считаются, а латинские не считаются.

## 📥 Формат ввода

Одна строка длиной до 100 символов (могут быть пробелы).

## 📤 Формат вывода

Одно число — количество гласных русских букв.

## 🧪 Примеры

**Пример 1**

Ввод:

```text
Привет мир
```

Вывод:

```text
3
```

**Пример 2**

Ввод:

```text
Программирование
```

Вывод:

```text
7
```

**Пример 3**

Ввод:

```text
Hello
```

Вывод:

```text
0
```
