## 🎯 Что это

## 🚀 Быстрый старт

1. Скачайте репозиторий: кнопка **Code → Download ZIP** на GitHub (или `git clone`).
2. Откройте задачу, например `tasks/level-1-start/task-1-1-change/README.md`, и прочитайте условие.
3. Пишите решение в файле `solve.py` в папке этой же задачи.
4. Запустите: `python solve.py` и введите данные руками.
5. Проверьте примеры из условия (из корня репозитория):

```bash
python check.py 1.1     # одна задача
python check.py 1       # весь уровень
python check.py         # все задачи
```

Нужен Python 3.8 или новее.

## 👥 Работа в команде

Разделите роли и меняйтесь ими после каждой задачи.

| Роль | Что делает |
|------|------------|
| 🧑‍✈️ Капитан | распределяет задачи, следит за временем |
| 👩‍💻 Кодер | пишет решение |
| 🕵️ Тестировщик | придумывает свои тесты и граничные случаи |
| 🔍 Ревьюер | читает код, ищет ошибки, предлагает улучшения |

## 🧪 Честная игра

- Примеры в условии — не все тесты. Скрытые тесты строже.
- Каждая команда решает задачи сама, переписывать чужие решения нельзя.
- Не копируйте готовые решения из интернета и от нейросетей: вы же пришли учиться 😉
