# Сервер API и административное управление

Сервис `app.py` использует только стандартную библиотеку Python и SQLite. Рабочий файл `tasks-private.json`, база прогресса и файл `admin-token` остаются на сервере и не добавляются в Git. В конфигурации хранятся входные данные, точный ожидаемый JSON и фрагмент ссылки для каждого задания.

## Публичный API

Базовый адрес: `http://192.144.13.123:8765`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/health` | состояние процесса |
| `GET` | `/api/tasks` | ID заданий |
| `GET` | `/api/tasks/{id}/input` | получить входной JSON |
| `POST` | `/api/submit` | проверить ответ и отметить задачу общей команде |
| `GET` | `/api/progress` | общий список решённых задач; итоговая ссылка после всех задач |

Пример тела отправки:

```json
{"task_id":"1.1","answer":{"change":127}}
```

Поля и типы должны совпасть точно. Верное решение сохраняется один раз для всей команды. Повторный верный запрос возвращает тот же фрагмент. Все фрагменты соединяются в порядке задач в конфигурации; ссылка открывается только после завершения всех настроенных задач.

## Закрытое администрирование

Админские маршруты намеренно возвращают обычный `404` без авторизации. Запросы принимаются только с локального адреса сервера или через локальный SSH-туннель, и требуют заголовок `X-Admin-Token`. Поэтому не вызывайте эти маршруты напрямую через открытый HTTP-порт.

| Метод | Путь | Тело / действие |
|---|---|---|
| `GET` | `/_admin/status` | количество задач и общий прогресс |
| `GET` | `/_admin/tasks` | закрытый просмотр конфигурации заданий |
| `POST` | `/_admin/tasks` | добавить `{ "id", "input", "expected", "fragment" }` |
| `PUT` | `/_admin/tasks/{id}` | заменить `{ "input", "expected", "fragment" }`; прогресс этой задачи сбрасывается |
| `DELETE` | `/_admin/tasks/{id}` | удалить задачу и её запись о прогрессе |
| `POST` | `/_admin/progress/reset` | `{"task_id":"3.2"}` сбросит одну задачу; `{"all":true}` — весь прогресс команды |

Токен находится в `/home/codex/team-endpoint/admin-token` с правами только владельцу сервиса. Получайте его через SSH и не сохраняйте в репозитории. Пример локального туннеля (оставьте соединение открытым):

```sh
ssh -L 18765:192.144.13.123:8765 quart@192.144.13.123
```

Затем обращайтесь к `http://127.0.0.1:18765`, добавляя заголовок `X-Admin-Token`. Например, статус:

```sh
curl -H "X-Admin-Token: $ADMIN_TOKEN" http://127.0.0.1:18765/_admin/status
```

## Файл конфигурации

Скопируйте пример и заполните private-конфигурацию только на сервере. Не добавляйте рабочую конфигурацию, ответы и фрагменты ссылки в Git.

```sh
cp tasks-private.example.json tasks-private.json
chmod 600 tasks-private.json
```

Каждый элемент `tasks` имеет ровно четыре поля: уникальный `id`, объект `input`, объект `expected` и строковый `fragment`. Максимум — 20 задач. `contest_url_prefix` и `contest_url_suffix` обычно пустые, если полная ссылка разрезана на фрагменты.

Сервис запускается из systemd как пользовательская служба `team-endpoint.service`. После обновления `app.py` перезапустите её командой `systemctl --user restart team-endpoint`.
